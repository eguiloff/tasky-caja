Google Sheets

La planilla es la fuente de verdad. La app lee al abrir y escribe cuando guardas.

Conexión

La conexión con Google funciona cuando el archivo está publicado en un dominio que autorizaste (GitHub Pages, tu hosting). Abierto como archivo local o dentro de una vista previa, Google bloquea la autenticación.
Cómo obtener el Client ID
  1. En Google Cloud Console, crea un proyecto y habilita la Google Sheets API.
  2. En Credenciales, crea un ID de cliente de OAuth del tipo Aplicación web.
  3. En Orígenes autorizados de JavaScript agrega el dominio donde subas este archivo.
  4. Copia el ID que termina en .apps.googleusercontent.com y pégalo arriba.
  5. Comparte la planilla con las cuentas que van a usar el sistema.
